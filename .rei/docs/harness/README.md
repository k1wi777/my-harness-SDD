# Documentación de REI Harness

Estos archivos definen **cómo funciona el arnés** — workflow, especificaciones, progreso y metadatos.

No requieren personalización al adaptar REI Harness a un proyecto concreto. Modifícalos solo si estás extendiendo o ajustando la herramienta.

| Archivo | Propósito |
|---------|-----------|
| `workflow.md` | Flujo de Work Items, estados y transiciones. |
| `specs.md` | Spec Driven Development y formatos de planificación. |
| `progress.md` | Sistema de progreso y plantillas de `.rei/progress/` y `.rei/progress/work-items/`. |
| `meta.md` | Estructura y significado de `meta.json`. |
