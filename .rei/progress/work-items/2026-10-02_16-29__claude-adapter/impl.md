# Implementación — Adaptador de Claude Code

> Work Item: `2026-10-02_16-29__claude-adapter` (task).
> Implementer · estado final: `review`.

## Resumen

Se añade el adaptador del runtime **Claude Code** al CLI `rei`, reutilizando la
infraestructura de adaptadores existente, y se documenta **Cursor** y **Codex**
como runtimes sin subagentes nativos que funcionan por *fallback*.

Para ello se generalizó `internal/adapter` con un descriptor `runtime`
(`name`, `hostedDir`, `mark`, `nativeKey`, `validTargets`, `buildData`) y
funciones genéricas (`loadToolMap`, `validateToolMap`, `resolveTargets`,
`renderAgent`, `generateAll`, `check`, `install`). `opencode.go` pasa a ser la
declaración del runtime OpenCode y `claude.go` la del runtime Claude; se
conservan `Install`/`Check` (OpenCode, firma intacta) y se exponen
`InstallClaude`/`CheckClaude`.

`rei init claude` genera `.claude/agents/<rol>.md` con frontmatter nativo
(`name`, `description`, `tools` coma-separados, `model` opcional), la marca
`GENERATED` y el `## Contrato` como cuerpo; `rei init claude --check` verifica
sin escribir. Se completaron los 9 pasos de `plan.md` sin modificar la
planificación ni ampliar el alcance.
